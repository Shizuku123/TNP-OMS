COMMON ISSUES AND SOLUTIONS:
===============================================

ISSUE 1: No browser console logs at all
SOLUTION: 
- Hard reload page (Ctrl + Shift + R)
- Clear browser cache
- Try incognito mode

ISSUE 2: "📤 Sending POST request" but no "📬 Response received"
SOLUTION:
- Check if XAMPP Apache is running
- Verify mail.php exists in: C:\xampp\htdocs\TNP-OMS-Firebase-v3.4\mail.php
- Check file permissions

ISSUE 3: PHP log shows "❌ EXCEPTION IN sendVolunteerWelcomeEmail()"
SOLUTION:
- Check the exception message in error log
- Common causes:
  * Gmail authentication failure
  * SMTP connection blocked by firewall
  * Invalid Gmail app password

ISSUE 4: Everything logs success but no email received
SOLUTION:
- Check spam/junk folder
- Verify Gmail account "coffeecornerofficial1@gmail.com" is not blocked
- Check Gmail "Less secure apps" or use App Password
- Try sending to different email address

ISSUE 5: "Response status: 500" error
SOLUTION:
- Check PHP error log for syntax errors
- Verify PHPMailer is installed in C:\xampp\htdocs\TNP-OMS-Firebase-v3.4\PHPMailer\

GMAIL SMTP TROUBLESHOOTING:
===============================================

If PHPMailer reports SMTP authentication errors:

1. VERIFY GMAIL APP PASSWORD
   - Go to: https://myaccount.google.com/apppasswords
   - Login with coffeecornerofficial1@gmail.com
   - Generate new app password for "Mail"
   - Replace password in mail.php line 434

2. CHECK GMAIL SETTINGS
   - Ensure 2-factor authentication is enabled
   - Enable "Less secure app access" if using regular password
   - Check if account is locked or suspended

3. TEST SMTP CONNECTION
   - Try different port (465 with SSL instead of 587 with TLS)
   - Check firewall isn't blocking port 587
